## Overview

This project is a single-page fitness and gym website homepage. It combines promotional content, fitness guidance, nutrition information, BMI reference material, and trainer profiles in one layout.

The page is organized into the following sections:

- **Hero section:** Main introduction, navigation, and call-to-action links.
- **Change Your Habits:** Content focused on building healthier routines.
- **Running promotion:** A dedicated promotional section for running and fitness.
- **Nutrition:** Meal-planning and nutrition-related content cards.
- **BMI information:** BMI guidance, a category chart, and a form interface.
- **Meet Our Team:** Trainer profile section.
- **Footer:** Additional navigation and site information.

## Technologies Used

- **HTML5** — page structure and content.
- **CSS3** — layout, styling, responsive behavior, and hover effects.
- **Font Awesome** — iconography.
- **Google Fonts** — Inter and Azeret Mono typography.
- **Miama** — decorative typography.

## Features

- Single-page fitness website layout.
- Navigation and hero call-to-action links.
- Fitness and healthy-habit content sections.
- Running promotion area.
- Nutrition and meal-planning cards.
- BMI information with a category reference chart.
- BMI form interface.
- Trainer/team profile section.
- Responsive styling for different screen sizes.
- Hover effects and custom typography.

> **Note:** The repository includes a BMI form interface. This README does not describe it as a working BMI calculator because a calculation implementation was not confirmed in the inspected source.

## Getting Started

No build step or package installation is required for the basic static website.

### Run locally

1. Clone the repository:

   ```bash
   git clone https://github.com/SheikhNegarSultana/Fitness-Website-Homepage.git
   ```

2. Open the project folder:

   ```bash
   cd Fitness-Website-Homepage
   ```

3. Open `index.html` in your browser.

You can also use the **Live Server** extension in Visual Studio Code to preview the website locally.

## Implementation Notes

The project uses plain HTML and CSS to keep the page lightweight and straightforward to run. CSS handles the visual presentation, responsive layout, and interactive hover states, while external font and icon resources provide the typography and interface icons.
